## How it works

`main.ts` (Node 22, TypeScript) writes exactly that one word to `/output/entry.txt` and nothing else. It also checks the gate first: exactly one word of 1–99 characters.

Run it with:

```sh
node main.ts
```

Then read `/output/entry.txt` back to confirm the match.
